# YeSymbol v1.0.0-rc15 性能与分类调整报告

## 数据基线

- 唯一符号或 Unicode 序列：16,679
- 生成后的静态分类：24
- 同组重复：0
- 同分类重复：0
- 每个普通分组最多12列
- 顶部最近使用最多14项

## 自动插入

旧关键路径：

```text
复制 → 保存最近使用 → 保存常用频次 → 切换窗口 → 固定等待25ms → Ctrl+V
```

rc15：

```text
复制 → 恢复此前窗口及焦点控件 → Ctrl+V
     → 更新内存中的最近使用/常用频次
     → 350ms内合并写入注册表
```

实现变化：

- 使用 `GetGUIThreadInfo` 记录目标焦点控件；
- 必要时使用 `AttachThreadInput` 恢复跨线程焦点；
- 删除固定 `Sleep(25)`；
- 最近、常用、自定义使用同一个延迟写入计时器；
- 退出前强制刷新尚未写入的记录。

## 启动关键路径

- 托盘图标延后初始化；
- 主符号区和最近使用区的悬浮提示窗口延后初始化；
- 首次界面只创建必要控件、加载小型注册表记录并构建“常用符号”；
- 符号目录仍直接编译进 EXE，启动时不解析 TXT/JSON。

## 符号查找

生成器为完整 UTF-16 序列构建 FNV-1a 开放寻址哈希表：

- 表大小：65,536槽
- 有效记录：16,679
- 装载率：约25.45%
- 全目录验证最大额外探测：5
- 平均额外探测：约0.156

该索引用于最近使用、常用、自定义和其他动态符号的双语名称查找，替代逐项扫描16,679条记录。

## 搜索

- 输入节流：90ms；
- 连续输入会取消前一次计时，只在暂停输入后重建结果；
- 静态符号使用位图标记去重；
- 最近、常用和自定义中的内置符号复用哈希索引与同一去重标记；
- 480项以上的搜索结果不再建立逐项 `YSLayoutItem`。

## GDI 绘图

主符号区复用一个与客户区同尺寸的兼容位图和内存 DC。窗口尺寸未变化时，滚动和悬停只清空并重绘现有缓冲，不再每次创建、选择、删除整套 GDI 对象。
