# YeSymbol v1.0.2 修改与检查报告

## 本版目标

1. 顶部最近使用由14项调整为17项，并让17个槽位横向铺满可用区域。
2. 常用符号取消按使用次数排序，改为用户维护的固定顺序。
3. 非常用符号累计使用达到阈值后，自动追加到常用符号末尾。
4. 常用符号及自动加入计数持久化保存，并兼容旧版记录。
5. 常用符号支持鼠标拖动排序和右键删除。
6. 版本更新为1.0.2。

## 最近使用

配置：

```c
#define YS_RECENT_MAX_VISIBLE 17
```

最近使用单元格不再依赖固定宽度。绘制和命中测试根据 `recent_grid` 的实际客户区宽度计算：

```text
left  = width × index / 17
right = width × (index + 1) / 17
```

因此第1项从左边开始，第17项到达右边，整数除法产生的余数会自然分配到各单元格，不会在右侧留下一个固定的大空白区。

## 常用符号固定顺序

旧版在增加和使用符号后会调用排序函数，根据 `use_count` 重新排序。

v1.0.2 已删除常用列表排序逻辑：

- 默认常用符号按数据中的原始顺序加入；
- 手工添加追加到列表末尾；
- 自动添加追加到列表末尾；
- 点击已有常用符号只增加累计次数，不改变位置；
- 拖动后的数组顺序直接持久化保存。

常用区标题改为：

```text
常用符号（拖动排序，右键删除）
```

每行继续固定显示12项。

## 自动加入常用

阈值集中配置在：

```text
include\ui_config.h
```

默认值：

```c
#define YS_COMMON_AUTO_ADD_THRESHOLD 5u
```

处理流程：

```text
用户复制或自动插入某符号
→ 符号已经在常用：只增加累计次数，不移动位置
→ 符号不在常用：增加 UsageV1 计数
→ 计数达到5次：追加到 CommonV2 末尾
→ 从 UsageV1 删除该临时计数
```

手工右键“添加到常用符号”时，会保留此前已经累计的使用次数，并立即停止使用临时计数记录。

用户从常用符号删除后，该符号的自动加入计数会重置；后续需要重新累计达到阈值才会再次自动加入。

## 持久化与迁移

注册表路径：

```text
HKEY_CURRENT_USER\Software\YeTools\YeSymbol
```

本版使用：

```text
CommonV2  REG_BINARY  常用符号文本、固定顺序、累计次数、序列号
UsageV1   REG_BINARY  尚未加入常用符号的累计次数
```

兼容规则：

```text
优先读取 CommonV2
→ 找不到时读取旧版 CommonV1
→ 保留旧版当前数组顺序
→ 自动写入 CommonV2
```

不会因为升级清空已有常用符号。

## 拖动排序

拖动只在以下状态生效：

```text
当前分类为“常用符号”
并且搜索框为空
```

操作：

```text
按住一个常用符号
→ 移动超过系统拖动阈值
→ 目标符号高亮
→ 松开鼠标
→ 移动到目标索引
→ 延迟写入 CommonV2
```

普通单击仍然复制符号；发生过拖动时不会误触发复制。

删除继续使用右键菜单：

```text
从常用符号删除
```
