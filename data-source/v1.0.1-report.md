# YeSymbol v1.0.1 修改与检查报告

## 本版目标

1. 常用符号固定每行显示12个。
2. Emoji由GDI单色字体绘制升级为DirectWrite + Direct2D颜色字体绘制。
3. 关于窗口增加可点击GitHub仓库链接。
4. 版本更新为1.0.1。
5. 按指定目录重写README。

## 常用符号布局

常用符号页不再依赖固定单元格宽度计算列数，而是：

```text
可用网格宽度
÷ 12列
→ 均分每个单元格
```

最后一个单元格右边界强制对齐网格右边缘，避免窗口边框、滚动条或客户区宽度取整导致第12项被裁掉。

## 彩色Emoji绘制

新增：

```text
include/emoji_renderer.h
src/emoji_renderer.c
```

绘制流程：

```text
GDI绘制背景和边框
→ 收集当前可见Emoji
→ DirectWrite使用Segoe UI Emoji进行文本整形
→ Direct2D DrawText启用颜色字体标志
→ 批量绘制到内存DC
→ BitBlt到窗口
```

核心颜色字体选项：

```text
D2D1_DRAW_TEXT_OPTIONS_ENABLE_COLOR_FONT
```

失败回退：

```text
DirectWrite/Direct2D初始化失败
或当前帧绘制失败
→ 使用原GDI Emoji字体路径
```

这样不会因为图形组件异常影响符号复制和程序基本使用。
