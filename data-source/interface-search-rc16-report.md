# YeSymbol v1.0.0-rc16 搜索定位与界面调整报告

## 本版范围

本版只处理用户提出的搜索结果信息、原始位置跳转、搜索历史、侧边栏交互、界面尺寸、数据链路检查和README重写；rc15的启动、搜索节流、虚拟绘制和自动插入性能优化继续保留。

## 1. 搜索结果悬浮信息

悬浮格式统一为：

```text
符号：
中文名称：
英文名称：
分类：
信息：
编码：
```

搜索结果不再把“搜索结果”作为所属分类。构建阶段为每个内置符号生成 `YSSymbolOriginRecord`，记录：

```text
原始分类索引
原始分组索引
分类行号
该行中的位置
分组内部项目位置
```

典型回归结果：

```text
😤 → Emoji·表情与人物，第30行，第10个
♉ → 特殊符号，第10行，第2个
𓀀 → 古埃及文字，第1行，第1个
```

## 2. 右键跳转

内置符号右键菜单增加：

```text
跳到所在位置
```

执行后会：

```text
保存当前搜索历史
→ 清空搜索
→ 必要时展开“其他符号”
→ 选择原始分类
→ 重建分类视图
→ 滚动到目标行
→ 高亮目标格
```

内部“补充符号”不显示侧边栏入口，因此对应项目会定位到“全部符号”中的同一字符；底部信息仍保留其原始分类。

## 3. 来源位置完整性

过去有655个非Emoji内置记录只存在于名称表，没有可浏览位置。转换器现在把这类记录自动放入：

```text
补充符号
└─ 未分类补充
```

该分类继续隐藏于侧边栏，但会参与“全部符号”和搜索定位。Emoji肤色或表现形式变体仍不重复占用格子，而是继承基础序列的位置。

检查结果：

```text
符号记录：16679
来源位置记录：16679
无有效来源位置：0
全部符号中的可见非变体：14988
自动归位的非Emoji记录：655
```

## 4. 搜索历史

新增最多32条搜索历史，保存在：

```text
HKCU\Software\YeTools\YeSymbol\SearchHistory
```

搜索框按键：

```text
↑      回显更早记录
↓      回显较新记录或返回当前草稿
Enter  确认并记入历史
Esc    清空搜索
```

重复搜索不产生重复记录，最近使用的搜索会移到最前面；注册表写入继续使用延迟合并，不阻塞输入。

## 5. “其他符号”和侧边栏

标题改为：

```text
其他符号⯈
其他符号⯆
```

调整内容：

- 与普通分类使用相同的字体、字号和字重；
- 不再使用粗体；
- 点击后选择状态停留在标题本身；
- 展开或折叠不会把当前内容切回“常用符号”；
- 鼠标悬停分类项时显示淡蓝色响应背景。

## 7. TXT → JSON → C 链路

确认流程保持为：

```text
data-source\catalog.txt
→ data-source\catalog.generated.json
→ src\symbol_data.c
→ yesymbol.exe
```

`catalog.generated.json` 是构建中间文件。Python生成器读取JSON并输出静态C数组，`yesymbol.exe` 运行时不读取JSON，因此：

- 不增加启动时JSON解析；
- 不增加外部运行文件；
- 不改变单EXE发布；
- TXT、JSON和C数量可以由静态检查相互核对。
