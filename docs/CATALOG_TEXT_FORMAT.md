# `catalog.txt` 格式说明

`data-source/catalog.txt` 是 YeSymbol 的人工维护主文件。设计目标是：看起来接近普通 Markdown 文本，增加或删除一行时不需要维护列数和行号。

## 最常用的写法

```text
# 序号字母
@desc 数字、分数、编号以及装饰字母。

## 黑底带圈数字
❶,❷,❸,❹,❺,❻,❼,❽,❾,❿
⓫,⓬,⓭,⓮,⓯,⓰,⓱,⓲,⓳,⓴

---

## 上标数字
⁰,¹,²,³,⁴,⁵,⁶,⁷,⁸,⁹
```

不再使用：

```text
@cols
@row
- ["❶","❷"]
```

转换器会自动完成：

- `cols` 和 `row` 全部自动生成；
- 一行不超过12项时保留为一行；
- 像 A-Z 这种超过12项的长行会自动按12项换行；
- 新增或移动一行不需要修改后续序号；
- `---` 表示视觉空白分隔。

## 逗号分隔

普通符号直接用英文逗号分开：

```text
♈,♉,♊,♋,♌,♎,♏,♐,♑,♓,♒,♍
```

多字符项目也可以不加引号：

```text
i:,ə:,ɔ:,u:,ɑ:
ai,ei,ɔi,au,əu,iə,eə,uə
tr,ts,t∫,dʒ
👨‍💻,👩‍💻,🇨🇳
```

普通项目不使用双引号。只有空格、分隔逗号、双引号本身或内容中含逗号时才使用双引号，例如：

```text
" "          半角空格
"　"         全角空格
","          逗号本身
""""         双引号本身（四个双引号）
"a,b"        内容本身包含逗号
```

TXT 使用标准 CSV 转义规则：字段内部的 `"` 写成两个 `""`。不要为了好看在逗号前后额外加入空格，因为空格可能本身就是要复制的内容。

## 分类与分组

```text
# 特殊符号
@desc 常用特殊符号。

## 星座
♈,♉,♊,♋,♌,♎,♏,♐,♑,♓,♒,♍
```

- `# 分类名` 开始一级分类，`#分类名` 也能识别；
- 一级分类下面可以直接写符号，不强制先写 `## _`；
- `## 分组名` 开始可选的二级分组；
- 无标题行不再需要专门补 `## _`，旧写法仍兼容；
- `@desc` 只保存数据备注，主界面不显示描述行；
- `#`、`##` 和 `@desc` 后面的显示文字都可以自由修改，转换器不会根据标题文字判断数据含义；
- 完全同名的一级或二级标题会按首次出现位置自动合并；
- 左侧分类顺序直接采用正文中一级分类的出现顺序，不再使用 `@ui-categories` 白名单；
- “全部符号”由工具自动生成，不在 TXT 中重复维护。

### 侧边栏区域

使用结构指令控制后续一级分类放在侧边栏的哪个区域：

```text
@ui-section main
# 普通分类

@ui-section emoji
# Emoji 子分类

@ui-section other
# 其他符号子分类

@ui-section hidden
# 仅搜索、不在侧边栏显示的分类
```

可用值：

- `main`：直接显示在侧边栏；
- `emoji`：放在侧边栏 `Emoji` 父级下面；
- `other`：折叠到“其他符号”下面；
- `hidden`：不显示在侧边栏，但仍参与搜索和“全部符号”。

该指令只控制结构，不是显示标题。修改分类名、分组名或说明文字时不需要改它。

### 常用符号默认项

常用符号与其他分类一样直接维护：

```text
# 常用符号
@role common
☆,★,○,●,□,■
```

目录中必须且只能有一个 `@role common` 分类，最多 256 项。用户已经追加、排序或删除的项目保存在 `CommonV3`；重新生成默认项后，程序会合并新增和移除项，不覆盖用户修改。旧的 `@default-common` 写法不再导出。

## 名称标注

文件末尾使用竖线分隔名称字段：

```text
#@symbols
@symbol ♉|金牛座|TAURUS|false
@symbol 😀|笑脸|GRINNING FACE|emoji
```

依次是：符号、中文名称、英文名称、是否使用 Emoji 字体。英文名称中的普通空格不需要引号。只有字段本身含有竖线、首尾空格或引号时才加双引号。

## 转换命令

```powershell
python tools\catalog_text.py check
python tools\catalog_text.py build
```

开发时直接运行：

```powershell
.\build.bat run
```

`run` 已经自动调用数据生成。也可以只生成数据而不编译：

```powershell
.\build.bat data
```

`export` 会根据 JSON 重新覆盖 `catalog.txt`，已经人工修改后不要随意执行：

```powershell
python tools\catalog_text.py export
```

## 去重规则

- 完全同名的一级标题自动合并，后续内容追加到第一次出现的位置；
- 完全同名的二级标题自动合并，后续内容追加到第一次出现的位置；
- 同一分组内部重复，只保留第一次；
- 同一分类的不同分组重复，有标题的人工分组优先；
- 不同分类允许出现同一个符号；
- “全部符号”自动生成唯一并集；
- 唯一符号不会因为去重而丢失。


## CLDR 中文名称

生成 JSON 时，转换器会读取：

```text
data-source\cldr-annotations-zh.tts.json
```

匹配规则：

- 使用 CLDR `type="tts"` 的简短中文名称；
- 符号和缓存键比较时忽略 `U+FE0F`；
- Emoji 名称优先采用 CLDR；
- 普通符号仅在当前名称为空、未标注或明显中英文机械混拼时替换；
- 人工校订且质量正常的普通符号名称继续保留。

刷新并写回 `#@symbols`：

```powershell
.\build.bat cldr
```

只把已有缓存应用到 TXT：

```powershell
python tools\catalog_text.py apply-cldr
```
