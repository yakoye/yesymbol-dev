# 使用说明

## 1. 启动和退出

双击 `yesymbol.exe` 启动。

YeSymbol 是单实例程序：再次运行 `yesymbol.exe` 时，不会创建第二个窗口，而是恢复现有窗口。

### 关闭到托盘

单击窗口右上角关闭按钮不会退出程序，而是隐藏到系统托盘。

```text
双击托盘图标                 恢复窗口
托盘右键 → 打开符号大全      恢复窗口
托盘右键 → 退出              真正退出
```

若 Windows Explorer / 任务栏重启，程序会尝试重新添加托盘图标。

## 2. 界面区域

### 顶部第一行

- “最近使用 ▼”用于展开或折叠最近使用区域；
- 搜索框内显示占位提示，输入后右侧出现 `×` 清空按钮；
- “自动插入”；
- “置顶”。

### 顶部第二行

固定显示最近使用的前17个符号。右侧垃圾桶按钮用于清空最近使用记录。

### 左侧

左侧分类从“常用符号”开始。“全部符号”固定在倒数第二项，“自定义”固定在最后一项。`Emoji` 和“其他符号”是带子分类的父级：

```text
Emoji
    笑脸
    手势
    人物
    人物活动
    家庭
    情绪
    植物
    动物
    食物
    活动
    旅行
    物体
    符号
    旗帜

其他符号
    日文字符
    韩文字符
    东亚字符
    俄文字符
    古埃及文字
    象形文字
```

点击折叠状态的 `Emoji` 会展开并直接显示“笑脸”；再次点击 `Emoji` 会折叠子分类，但右侧当前内容保持不变。“其他符号”采用相同行为，展开时直接显示“日文字符”。

“补充符号”不再单独显示在侧边栏，但其内容仍可通过搜索和“全部符号”访问。

### 右侧

显示当前分类的分组标题和符号网格。滚轮第一次到达底部时会停住；松开滚轮或触摸板、短暂停顿后重新向下滚，才进入左侧的下一个分类。向上也采用相同规则。连续滚动和触摸板惯性不会直接跨分类。顺序贯穿普通分类、Emoji 子分类、其他符号子分类，直到“全部符号”。选择“自定义”时，添加入口会显示在右侧主界面顶部。

### 底部

使用紧凑的单行信息区显示：

```text
符号  中文名称  Unicode编码  英文名称  所属分类
```

## 3. 复制符号

单击符号即可复制到剪贴板。

复制完成后，在目标应用中按：

```text
Ctrl + V
```

复杂 Emoji 和组合字符会作为完整 Unicode 序列复制，不会拆成单独码位。

## 4. 自动插入

勾选：

```text
自动插入
```

单击符号后，程序会恢复之前活动窗口中保存的焦点控件并发送粘贴命令。该勾选状态会保存在当前用户注册表，下次启动继续使用。

自动插入先于最近使用排序和注册表保存执行；记录写入会延迟合并，因此点击时不会等待每一次注册表操作。

注意：

- 某些应用不接受模拟粘贴；
- 不同权限级别之间可能受 Windows UIPI 限制；
- 管理员程序和普通权限程序之间尤其可能失败；
- 即使自动插入失败，符号通常仍已复制到剪贴板，可手动按 `Ctrl + V`。

## 5. 置顶

勾选“置顶”后，主窗口会保持在其他普通窗口前面。

程序启动时当前窗口使用置顶扩展样式；取消选中后会切换为普通窗口层级。

## 6. 搜索

搜索会同时匹配：

- 符号文本；
- 中文名称；
- 英文名称；
- 分类名称；
- 十六进制 Unicode 编码。

示例：

```text
→
箭头
arrow
2192
U+2192
金牛座
Taurus
版权
Copyright
```

点击搜索框内部右侧的 `×`，或清空输入内容，即可恢复当前分类视图。

搜索框会保留最近32条非空搜索。搜索框获得焦点时：

```text
↑      回显更早的搜索
↓      回显较新的搜索或返回当前输入草稿
Enter  确认当前搜索并写入历史
Esc    清空搜索
```

## 7. 悬浮提示

鼠标停留在符号上时会显示：

```text
符号：♉
中文名称：金牛座
英文名称：TAURUS
分类：特殊符号
信息：第 10 行，第 2 个
编码：U+2649
```

对于多码位 Emoji，会显示完整的多个 Unicode 编码。搜索结果中的“分类”和“信息”来自符号的原始目录位置，不会显示成“搜索结果”。

在搜索结果或其他内置符号上单击右键，可以选择：

```text
跳到所在位置
```

程序会清空搜索、展开必要的 `Emoji` 或“其他符号”分组、选择原始分类并滚动到对应行。

## 8. 最近使用

最近使用固定在窗口顶部，不占用左侧分类位置：

- 完整记录最大容量为64；
- 顶部最多显示最新的17个；
- 最新使用的排在前面；
- 重复使用会移动到前面；
- 右键可删除某一项；
- 点击“最近使用 ▼”可以折叠；
- 点击右侧垃圾桶可以清空全部记录。

## 9. 常用符号

“常用符号”相当于带频率排序的收藏夹。

### 添加

在任何符号上单击右键，选择：

```text
添加到常用符号
```

### 删除

右键已经收藏的符号，选择：

```text
从常用符号删除
```

### 排序

- 使用次数越多，位置越靠前；
- 使用次数相同时，较早收藏的排在前面；
- 最大容量为 256。

## 10. 自定义符号

在左侧选择“自定义”，右侧主界面顶部会出现：

```text
手动添加自定义符号
[输入一个或多个自定义符号] [添加]
```

添加后的符号显示在下方网格中。删除方法：

```text
自定义分类 → 右键符号 → 从自定义删除
```

最大容量为128。

## 11. 用户数据位置

数据存储在当前用户注册表：

```text
HKEY_CURRENT_USER\Software\YeTools\YeSymbol
```

主要值：

```text
Recent       最近使用
Custom       自定义符号
CommonV2     常用符号、累计次数和固定顺序
UsageV1      尚未加入常用符号的累计使用次数
AutoInsert   自动插入勾选状态
SearchHistory 最近搜索记录
```

### 备份

```powershell
reg export "HKCU\Software\YeTools\YeSymbol" yesymbol-user-data.reg /y
```

### 恢复

```powershell
reg import .\yesymbol-user-data.reg
```

### 清空

先从托盘退出程序，然后执行：

```powershell
reg delete "HKCU\Software\YeTools\YeSymbol" /f
```

该操作不可撤销；有需要时先导出备份。

## 12. 便携使用

`yesymbol.exe` 本身可以放在任意目录、U 盘或工具文件夹中运行，不要求安装。

但“最近使用、常用和自定义”保存在注册表，因此它们属于当前 Windows 用户，而不是跟随 EXE 移动。

## 13. 显示问题

### 4K 或多显示器显示

程序支持 Per-Monitor V2 DPI。窗口在 125% 与 150% 缩放显示器之间移动时，会自动补偿标题栏、边框、滚动条和顶部复选框宽度；主网格始终保留完整 12 列，36×36 Emoji 不会被粗暴放大。

### 显示为方框

说明当前系统字体可能不包含该字形。可以：

- 更新 Windows；
- 安装覆盖该 Unicode 区块的字体；
- 在源码中修改字体设置并重新编译。

### Emoji 图片没有显示

程序优先显示内嵌的 36×36 Twemoji 图片；缺图时回退到系统 Emoji 字体。无论显示路径如何，复制得到的始终是原始 Unicode 序列。


## Emoji 与肤色变体

- Emoji 按“笑脸、手势、人物、人物活动、家庭、情绪、植物、动物、食物、活动、旅行、物体、符号、旗帜”整理为 14 个侧栏子分类。
- Emoji 分类默认优先显示基础/黄色皮肤版本，避免同一表情被不同肤色重复占满。
- 如果某个 Emoji 支持肤色变体，右键它会出现“切换肤色”子菜单，可直接复制浅肤色、中浅肤色、中等肤色、中深肤色和深肤色版本。
- 最近使用和主网格共用同一套图片渲染，点击图片仍复制或插入 Unicode。

## 布局规则

- 所有分组每行最多显示 12 个符号。
- 行数增多时，使用滚动条浏览。


## 性能行为

- 搜索连续输入会在停止输入约90毫秒后统一执行；
- “全部符号”、象形文字、古埃及文字等大分类只绘制可见行；
- 数据仍然编译在 EXE 内，不会首次打开分类时读取外部 JSON；
- 主符号区复用内存绘图缓冲，滚动和悬停不会为每一帧重新创建整套 GDI 缓冲；
- Emoji 图片按需解码，位图缓存最多保留 384 项，不会在后台预热全部目录；
- 关闭或退出前会把尚未写入的最近使用、常用和自定义记录同步保存。

## 打开“关于”

可以通过以下任一入口：

```text
点击主窗口左上角图标 → 关于 YeSymbol...
托盘图标右键 → 关于 YeSymbol
```

关于窗口包含版本、修改日期、开发目的、联系邮箱、GitHub、Unicode List 和网页版入口。链接可直接打开。


## 常用符号顺序

常用符号不再按使用次数排序。在“常用符号”页面按住符号并拖到目标位置即可重排；右键可删除。非常用符号累计使用达到 `YS_COMMON_AUTO_ADD_THRESHOLD` 后自动追加到末尾。默认内容来自 `catalog.txt` 的 `# 常用符号`，重新生成与升级后仍保留用户追加、排序和删除结果。
